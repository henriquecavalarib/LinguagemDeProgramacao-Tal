# Tal

Tal é uma mini linguagem baseada no paradigma imperativo com foco em alteração explícita de estado e controle de fluxo.

## Pré-requisitos

- Python 3.8 ou superior instalado.

## Como Executar

1. Salve o arquivo do interpretador como `tal.py`.
2. Abra o terminal no diretório onde o arquivo está localizado.
3. Execute o programa usando o comando:

```bash
python tal.py
